Blinkit Sales Dashboard : A Power BI Project 

I developed a dynamic sales dashboard for Blinkit, India's "Last Minute App," using Microsoft Power BI.
This project transformed raw sales data into actionable insights. Through a comprehensive process of data cleaning and transformation in Power Query, I created a clean and reliable dataset. From there, I built an interactive dashboard that visualizes key performance indicators (KPIs) and helps identify top-performing outlets and product categories. This project showcases my skills in data modeling, and creating user-friendly visualizations to drive better business decisions.
